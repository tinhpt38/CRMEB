# Mô tả chi tiết cấu trúc thư mục frontend di động CRMEB

## 📋 Tổng quan dự án

**Stack công nghệ**: Vue.js 2.x + uni-app + Vuex + SCSS  
**Hỗ trợ đa nền tảng**: H5, WeChat Mini Program, Alipay Mini Program, Baidu Mini Program, Toutiao Mini Program, App  
**Phiên bản dự án**: CRMEB bản tiêu chuẩn 5.6.2  
**Mô hình phát triển**: Component hóa + Mô-đun hóa + Tải phân gói


## 📊 Phân tích chi tiết cấu trúc thư mục

### 1. 📁 api/ - Tầng dịch vụ interface

Quản lý API theo mô-đun nghiệp vụ, sử dụng Promise để đóng gói:

```javascript
// 文件结构
api/
├── activity.js      # 营销活动接口 (砍价、拼团、秒杀等)
├── admin.js         # 管理端接口
├── api.js           # 基础API接口
├── kefu.js          # 客服系统接口
├── lottery.js       # 抽奖活动接口  
├── order.js         # 订单管理接口
├── points_mall.js   # 积分商城接口
├── public.js        # 公共接口 (配置获取等)
├── store.js         # 门店相关接口
├── user.js          # 用户中心接口
```

**Đặc điểm thiết kế interface**:
- Cơ chế xử lý lỗi thống nhất
- Xác thực tham số request
- Chuẩn hóa dữ liệu response
- Hỗ trợ thích ứng môi trường đa nền tảng

## 🚀 Đặc tính kỹ thuật lõi

### 1. Cơ chế thích ứng đa nền tảng
```javascript
// 条件编译示例
// #ifdef H5
// H5特有代码
// #endif

// #ifdef MP-WEIXIN  
// 微信小程序特有代码
// #endif

// #ifdef APP-PLUS
// App特有代码
// #endif
```

### 2. Chiến lược tối ưu hiệu năng
- **Tải phân gói**: Phân gói theo mô-đun nghiệp vụ, giảm dung lượng gói chính
- **Lazy-load ảnh**: Chỉ tải khi ảnh vào vùng hiển thị khi cuộn
- **Lazy-load component**: Chia tách mã theo cấp route
- **Cache dữ liệu**: Chiến lược cache hợp lý
- **Chống rung request**: Tránh request trùng lặp

### 3. Hệ thống đổi giao diện theo chủ đề
Hỗ trợ chuyển màu chủ đề động, triển khai bằng biến CSS:
```css
:root {
  --view-theme: #e93323; /* 主要主题色 */
  --view-assist: #ff9900; /* 辅助色 */
}
```

### 4. Hỗ trợ quốc tế hóa
Hỗ trợ đa ngôn ngữ dựa trên Vue I18n, hỗ trợ tải gói ngôn ngữ động.

## 📋 Quy chuẩn phát triển

### 1. Quy chuẩn đặt tên
- **Đặt tên thư mục**: Chữ thường, dùng dấu gạch nối `my-component`
- **Đặt tên file**: Component Vue dùng PascalCase `MyComponent.vue`
- **Đặt tên biến**: camelCase `userInfo`
- **Đặt tên hằng số**: Viết hoa và gạch dưới `API_BASE_URL`

### 2. Tổ chức mã
- Nguyên tắc trách nhiệm đơn nhất
- Xác thực props của component
- Xử lý biên lỗi
- Quy chuẩn comment hợp lý

### 3. Quy chuẩn commit
- feat: tính năng mới
- fix: sửa bug
- docs: cập nhật tài liệu
- style: định dạng mã
- refactor: tái cấu trúc mã
