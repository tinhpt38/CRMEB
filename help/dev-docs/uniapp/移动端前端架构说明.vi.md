# Thuyết minh kiến trúc frontend di động CRMEB

## 📱 Tổng quan stack công nghệ

| Công nghệ | Phiên bản | Mô tả |
|------|------|------|
| UniApp | 2.x/3.x | Framework phát triển đa nền tảng |
| Vue.js | 2.x/3.x | Framework lõi |

| Axios | HTTP客户端 | Đóng gói request |

## 🔧 Thực tiễn phát triển tốt nhất

### 1. Vòng đời trang
```javascript
export default {
  // 页面加载
  onLoad(options) {
    this.initPage(options)
  },

  // 页面显示
  onShow() {
    this.refreshData()
  },

  // 下拉刷新
  onPullDownRefresh() {
    this.loadData().finally(() => {
      uni.stopPullDownRefresh()
    })
  },

  // 上拉加载
  onReachBottom() {
    this.loadMore()
  },

  methods: {
    async initPage(options) {
      // 初始化页面数据
    },

    async refreshData() {
      // 刷新数据
    }
  }
}
```

### 2. Giao tiếp component
```javascript
// 父传子
<child-component :data="parentData" @custom-event="handleEvent" />

// 子组件
export default {
  props: {
    data: {
      type: Object,
      default: () => ({})
    }
  },
  methods: {
    emitEvent() {
      this.$emit('custom-event', eventData)
    }
  }
}
```

### 3. Quản lý trạng thái
```javascript
// 使用 Vuex
import { mapState, mapActions } from 'vuex'

export default {
  computed: {
    ...mapState('user', ['userInfo']),
    ...mapState('cart', ['cartList'])
  },
  methods: {
    ...mapActions('user', ['login']),
    ...mapActions('cart', ['addToCart'])
  }
}
```

## 🎯 Tối ưu hiệu năng

### 1. Tối ưu hình ảnh
```javascript
// 使用懒加载
<image lazy-load src="image.jpg" />

// 使用webp格式
<image webp src="image.webp" />

// 使用合适的图片尺寸
<image :src="imageUrl + '?x-oss-process=image/resize,w_300'" />
```

### 2. Cache dữ liệu
```javascript
// 使用本地存储
uni.setStorageSync('key', data)
const data = uni.getStorageSync('key')

// 使用内存缓存
const cache = new Map()
cache.set('key', data)
const data = cache.get('key')
```

### 3. Tối ưu request
```javascript
// 防抖处理
const debounce = (func, wait) => {
  let timeout
  return function() {
    clearTimeout(timeout)
    timeout = setTimeout(() => func.apply(this, arguments), wait)
  }
}

// 使用
search: debounce(function(keyword) {
  this.doSearch(keyword)
}, 300)
```

## 📦 Thích ứng đa nền tảng

### 1. Biên dịch có điều kiện
```javascript
// #ifdef H5
console.log('只在H5平台显示')
// #endif

// #ifdef MP-WEIXIN
console.log('只在微信小程序显示')
// #endif

// #ifdef APP-PLUS  
console.log('只在App显示')
// #endif
```

### 2. Xử lý khác biệt nền tảng
```javascript
const platform = {
  isH5: uni.getSystemInfoSync().platform === 'h5',
  isWeapp: uni.getSystemInfoSync().platform === 'devtools',
  isApp: uni.getSystemInfoSync().platform === 'app'
}

// 使用
if (platform.isH5) {
  // H5特有逻辑
}
```

## 🚀 Triển khai phát hành

### 1. Phát hành mini program
```bash
# 微信小程序
npm run build:mp-weixin
# 然后使用微信开发者工具上传

# 支付宝小程序  
npm run build:mp-alipay
```

### 2. Triển khai H5
```bash
# 构建H5
npm run build:h5

# 部署到服务器
scp -r dist/build/h5 user@server:/path/to/www
```

### 3. Phát hành App
```bash
# 构建App
npm run build:app

# 使用HBuilderX进行打包和发布
```
