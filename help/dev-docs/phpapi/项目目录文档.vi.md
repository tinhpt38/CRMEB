# Tài liệu danh mục dự án CRMEB

## 1. Giới thiệu
- **Mục đích tài liệu**: Mô tả chi tiết cấu trúc thư mục và chức năng của từng thư mục của dự án CRMEB
- **Phạm vi ứng dụng**: nhà phát triển dự án, người bảo trì, thành viên mới
- **Định nghĩa thuật ngữ**: Không có thuật ngữ đặc biệt

##2. Cấu trúc thư mục gốc của dự án

### 2.1 Cây thư mục

```
CRMEB/
├── .comate/            # Comate 工具配置
├── .env                # 环境配置文件
├── .git/               # Git 版本控制
├── .gitignore          # Git 忽略文件
├── .idea/              # IDEA 编辑器配置
├── .trae/              # Trae 工具配置
│   ├── rules/          # 规则配置
│   └── skills/         # 技能配置
├── crmeb/              # 核心应用目录
├── docker-compose/     # Docker 配置
├── docs/               # 文档目录
├── docs.zip            # 文档压缩包
├── LICENSE             # 许可证文件
├── readme/             # 说明文档
├── README.md           # 项目说明
├── template/           # 模板文件
└── 安装必读.docx       # 安装说明
```

### 2.2 Mô tả thư mục gốc
- **.trae/**: Thư mục cấu hình công cụ Trae, bao gồm các quy tắc và cấu hình kỹ năng
- **crmeb/**: Thư mục ứng dụng cốt lõi của dự án, bao gồm tất cả logic nghiệp vụ
- **docker-compose/**: Cấu hình bộ chứa Docker để triển khai nhanh chóng
- **docs/**: Thư mục tài liệu dự án, nơi lưu trữ nhiều tài liệu khác nhau
- **readme/**: Tài liệu mô tả dự án, bao gồm giới thiệu chức năng và ảnh chụp màn hình
- **template/**: Thư mục tệp mẫu, được sử dụng để tạo mã và cấu hình

## 3. Cấu trúc thư mục ứng dụng cốt lõi (crmeb/)

### 3.1 Cây thư mục

```
crmeb/
├── .constant           # 常量定义
├── .env                # 应用环境配置
├── .htaccess           # Apache 配置
├── .phpstorm.meta.php  # PHPStorm 元数据
├── .travis.yml         # Travis CI 配置
├── .version            # 版本信息
├── app/                # 应用核心目录
├── backup/             # 备份目录
├── build.example.php   # 构建配置示例
├── composer.json       # Composer 依赖配置
├── composer.lock       # Composer 依赖锁定
├── config/             # 配置文件目录
├── crmeb/              # 核心库目录
├── filetree.txt        # 文件树结构
├── index.html          # 入口 HTML
├── install.lock        # 安装锁定
├── LICENSE.txt         # 许可证文件
├── public/             # 静态资源目录
├── README.md           # 应用说明
├── route/              # 路由配置目录
├── runtime/            # 运行时目录
├── think               # ThinkPHP 命令行工具
├── vendor/             # 依赖库目录
└── workerman.bat       # Workerman 启动脚本
```

### 3.2 Mô tả thư mục lõi
- **app/**: Thư mục cốt lõi của ứng dụng, bao gồm tất cả logic nghiệp vụ
- **config/**: Thư mục file cấu hình, lưu trữ cấu hình ứng dụng
- **crmeb/**: thư mục thư viện lõi, cung cấp các chức năng cơ bản
- **public/**: Thư mục tài nguyên tĩnh, lưu trữ các file front-end
- **route/**: Thư mục cấu hình định tuyến, xác định định tuyến URL
- **runtime/**: thư mục thời gian chạy, nơi lưu trữ bộ đệm và nhật ký
- **nhà cung cấp/**: Thư mục thư viện phụ thuộc, các phụ thuộc được Composer cài đặt

## 4. Cấu trúc thư mục lõi ứng dụng (app/)

### 4.1 Cây thư mục

```
app/
├── adminapi/           # 后台 API 接口
├── api/                # 前端 API 接口
├── AppService.php      # 应用服务
├── build.php           # 构建配置
├── common.php          # 公共函数
├── dao/                # 数据访问层
├── event.php           # 事件配置
├── ExceptionHandle.php # 异常处理
├── filetree.txt        # 文件树结构
├── http/               # HTTP 相关
├── jobs/               # 队列任务
├── kefuapi/            # 客服 API 接口
├── lang/               # 语言包
├── listener/           # 事件监听器
├── middleware.php      # 中间件配置
├── model/              # 数据模型
├── outapi/             # 外部 API 接口
├── provider.php        # 服务提供者
├── README.md           # 目录说明
├── Request.php         # 请求基类
├── service.php         # 服务配置
└── services/           # 业务逻辑层
```

### 4.2 Mô tả thư mục lõi
- **adminapi/**: Giao diện API hệ thống quản lý backend, xử lý các yêu cầu backend
- **api/**: Giao diện API ứng dụng front-end, xử lý các yêu cầu của client
- **dao/**: Lớp truy cập dữ liệu, đóng gói các hoạt động của cơ sở dữ liệu
- **jobs/**: xếp hàng các tác vụ, xử lý các hoạt động không đồng bộ
- **kefuapi/**: Giao diện API của hệ thống dịch vụ khách hàng
- **model/**: Mô hình dữ liệu, xác định cấu trúc dữ liệu
- **outapi/**: Giao diện API hệ thống bên ngoài
- **services/**: Lớp logic nghiệp vụ để triển khai các chức năng nghiệp vụ cốt lõi

##5. Mô tả module lõi

### 5.1 Lớp điều khiển (api/, adminapi/, kefuapi/)
- Xử lý các yêu cầu HTTP
- phân phối tuyến đường
- Xác thực tham số
- Trả lời phản hồi

### 5.2 Lớp logic nghiệp vụ (services/)
- Triển khai logic kinh doanh cốt lõi
- Gọi lớp truy cập dữ liệu
- Xử lý các quy tắc kinh doanh

### 5.3 Lớp truy cập dữ liệu (dao/)
- Đóng gói các hoạt động cơ sở dữ liệu
- Cung cấp các phương thức truy vấn dữ liệu
- Xử lý sự kiên trì của dữ liệu

### 5.4 Lớp mô hình dữ liệu (model/)
- Xác định cấu trúc dữ liệu
- Mối quan hệ liên kết
- Xác thực dữ liệu

### 5.5 Lớp cấu hình (config/)
- Cấu hình ứng dụng
- Cấu hình cơ sở dữ liệu
- Cấu hình bộ đệm
- Cấu hình nhật ký

## 6. Thư mục tài nguyên tĩnh (public/)
- **css/**: tệp kiểu
- **js/**: tập tin JavaScript
- **hình ảnh/**: tập tin hình ảnh
- **phông chữ/**: tập tin phông chữ
- **tải lên/**: Tải tập tin lên

##7. Mô tả file cấu hình

### 7.1 Tệp cấu hình lõi
- **.env**: Cấu hình biến môi trường
- **config/app.php**: Cấu hình ứng dụng
- **config/database.php**: Cấu hình cơ sở dữ liệu
- **config/cache.php**: cấu hình bộ đệm

### 7.2 Cấu hình định tuyến
- **route/api.php**: Định tuyến API
- **route/adminapi.php**: Định tuyến API phụ trợ
- **route/kefuapi.php**: Định tuyến API dịch vụ khách hàng

##8. Mô tả file cốt lõi

### 8.1 Tệp nhập
- **public/index.php**: file nhập hồ sơ
- **nghĩ**: công cụ dòng lệnh

### 8.2 Lớp cơ bản
- **app/Request.php**: Yêu cầu lớp cơ sở
- **app/ExceptionHandle.php**: Lớp xử lý ngoại lệ
- **app/AppService.php**: Lớp dịch vụ ứng dụng

### 8.3 Tệp cấu hình
- **composer.json**: quản lý phần phụ thuộc
- **.htaccess**: Quy tắc viết lại của Apache

##9. Gợi ý sử dụng thư mục

### 9.1 Thông số kỹ thuật phát triển
- **Tệp mới**: được lưu trữ theo cấu trúc thư mục mô-đun tương ứng
- **Sửa đổi tập tin**: Giữ cấu trúc thư mục gốc
- **Xóa tệp**: Xóa sau khi xác nhận rằng không có phụ thuộc

### 9.2 Quy ước đặt tên
- **Tên thư mục**: chữ thường, không có ký tự đặc biệt
- **Tên tệp**: CamelCase hoặc chữ gạch dưới chữ thường
- **Tên lớp**: PascalCase
- **Tên phương thức**: CamelCase
