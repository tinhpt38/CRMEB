# Mô tả cấu trúc dự án CRMEB

##🏗️ Tổng quan kiến ​​trúc tổng thể

### ngăn xếp công nghệ
```
前端：Vue.js 2 + ElementUI + UniApp
后端：ThinkPHP 6.0 + 多应用模式
数据库：MySQL 5.7+
缓存：Redis
消息队列：Workerman
```

###Mẫu kiến ​​trúc
- **Mẫu MVC**: Kiến trúc phân lớp Model-View-Controller
- **Kiến trúc ba tầng**: Bộ điều khiển → Dịch vụ → DAO/Model
- **Tách biệt front-end và back-end**: Giao diện API và trang front-end được triển khai độc lập
- **Thích ứng nhiều thiết bị đầu cuối**: Hỗ trợ các chương trình nhỏ, thiết bị đầu cuối H5, APP và PC

##🔐 Cơ chế xác thực và ủy quyền

### Xác thực mã thông báo JWT
```
┌──────────────┐    请求携带 Token     ┌──────────────┐
│   前端应用    │ ──────────────────→  │   后端 API    │
└──────────────┘                       └──────────────┘
                                            ↓
                                    ┌──────────────┐
                                    │ 解析 Token   │
                                    │ 验证有效性   │
                                    └──────────────┘
                                            ↓
                                    ┌──────────────┐
                                    │ 获取用户 ID  │
                                    │ 注入请求     │
                                    └──────────────┘
```

### Kiểm soát quyền
- **Mô hình cấp phép RBAC**: Người dùng → Vai trò → Quyền
- **Quyền menu**: Kiểm soát hiển thị menu nền
- **Quyền sử dụng nút**: Kiểm soát việc hiển thị các nút thao tác
- **Quyền dữ liệu**: Kiểm soát phạm vi truy cập dữ liệu

### Hàng đợi tin nhắn (Workerman)
- Xử lý hết thời gian đặt hàng

- Đơn hàng tự động bị hủy
- Tóm tắt thống kê
- Tự động dọn dẹp bộ đệm
- Xử lý dữ liệu hết hạn

## 📈 Tối ưu hóa hiệu suất

### Chiến lược lưu vào bộ nhớ đệm
- **Bộ nhớ đệm giao diện**: Bộ nhớ đệm kết quả giao diện tần số cao
- **Bộ đệm trang**: Giảm chi phí hiển thị trang
- **Bộ nhớ đệm dữ liệu**: Giảm truy vấn cơ sở dữ liệu

### Tối ưu hóa cơ sở dữ liệu
- **Tách và ghi đọc**: sao chép master-slave, đọc từ Slave và ghi vào Master
- **Tối ưu hóa chỉ mục**: Thiết kế chỉ mục phù hợp
- **Phân tích truy vấn chậm**: Xác định các điểm tắc nghẽn về hiệu suất

### Tối ưu hóa mã
- **Lazy loading**: Tải dữ liệu theo yêu cầu
- **Tải trước**: Tải trước dữ liệu tiếp theo
- **Xử lý hàng loạt**: Giảm hoạt động vòng lặp

##🛡️ Cơ chế bảo mật

### Bảo mật giao diện
- **Lọc tham số**: Ngăn chặn việc tiêm SQL
- **Giới hạn tần suất**: Ngăn chặn các yêu cầu độc hại
- **Xác minh chữ ký**: Ngăn chặn giả mạo dữ liệu

### Bảo mật dữ liệu
- **Mã hóa nhạy cảm**: Lưu trữ mật khẩu và thông tin thanh toán được mã hóa
- **Bản ghi nhật ký**: Ghi lại toàn bộ hoạt động
- **Sao lưu và phục hồi**: Sao lưu dữ liệu thường xuyên
