# Tài liệu quy trình cài đặt hệ thống CRMEB

## 📋 Tổng quan về tài liệu

Tài liệu này cung cấp quy trình cài đặt hoàn chỉnh của hệ thống trung tâm mua sắm nguồn mở CRMEB, có thể áp dụng cho phiên bản CRMEB 5.6.4+.

## 🖥️ Yêu cầu về môi trường máy chủ

###Yêu cầu cấu hình cơ bản

| Mục cấu hình | Cấu hình tối thiểu | Cấu hình đề xuất |
|--------|---------|---------|
| CPU | 1 lõi | 2 lõi trở lên |
| Ký ức | 1GB | 2GB trở lên |
| Ổ cứng | SSD 20GB | SSD 50GB trở lên |
| Băng thông | 1Mbps | 5Mbps trở lên |

### Yêu cầu về hệ điều hành

| Loại hệ thống | Phiên bản được hỗ trợ |
|---------|---------|
| Linux | CentOS 7+/Ubuntu 18+/Debian 10+ |
| Windows | Máy chủ Windows 2012+ |
| macOS | Chỉ dành cho môi trường phát triển |

### Yêu cầu về môi trường phần mềm

| Phần mềm | Phiên bản tối thiểu | Phiên bản đề xuất | Mô tả |
|------|---------|---------|------|
| PHP | 7.1 | 7.4 | Tiện ích mở rộng PDO phải được bật |
| MySQL | 5,7 | 8.0 | Công cụ InnoDB được đề xuất |
| Làm lại | 3.0 | 7.0 | Tùy chọn, cải thiện hiệu suất |
| Nginx | ​​1.18 | 1,22 | Máy chủ proxy ngược |
| Nhà soạn nhạc | 1.8 | 2.x | Quản lý phụ thuộc PHP |
| Git | 2.0 | Phiên bản mới nhất | Kiểm soát phiên bản mã |

### Yêu cầu mở rộng PHP

```
必须开启的扩展：

```

## 🐳 Phương pháp 1: Triển khai Docker bằng một cú nhấp chuột (được khuyến nghị)

###1. Chuẩn bị môi trường

```bash
# 检查Docker是否安装
docker --version
# Docker version 20.10.x, build xxxxx

# 检查Docker Compose
docker-compose --version
# Docker Compose version v2.x.x

# 如未安装，请先安装Docker
# Ubuntu系统安装：
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# 安装Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/download/v2.20.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
```

### 2. Lấy mã dự án

```bash
# 克隆项目
git clone https://gitee.com/ZhongBangKeJi/CRMEB.git crmeb
cd crmeb

# 切换到稳定版本分支（根据需要选择）
git checkout -b v5.6.4 origin/v5.6.4
```

### 3. Cấu hình biến môi trường

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑环境变量
vim .env
```

```ini
# 数据库配置
DB_HOST=mysql
DB_PORT=3306
DB_DATABASE=crmeb
DB_USERNAME=root
DB_PASSWORD=crmeb123456

# Redis配置
REDIS_HOST=redis
REDIS_PORT=6379
REDIS_PASSWORD=

# 应用配置
APP_DEBUG=true
APP_URL=http://localhost

# Admin后台配置
ADMIN_HTTPS=false
```

### 4. Bắt đầu bằng một cú nhấp chuột

```bash
# 构建并启动所有服务
docker-compose up -d --build

# 查看服务状态
docker-compose ps

# 输出示例：
#   Name                 Command               State           Ports
# ----------------------------------------------------------------------
# crmeb-app     docker-php-entrypoint apach ...   Up              0.0.0.0:80->80/tcp
# crmeb-mysql   docker-entrypoint.sh mysqld ...   Up              3306/tcp
# crmeb-redis   docker-entrypoint.sh redis ...   Up              6379/tcp
```

### 5. Truy cập trình hướng dẫn cài đặt

Mở trình duyệt và truy cập: `http://your-server-ip`

Làm theo các bước của trình hướng dẫn cài đặt để hoàn tất quá trình cài đặt hệ thống:
1. Kiểm tra môi trường
2. Kiểm tra quyền thư mục
3. Cấu hình cơ sở dữ liệu
4. Cài đặt tài khoản quản trị viên
5. Cài đặt hoàn tất

### Lệnh quản lý Docker

```bash
# 启动服务
docker-compose start

# 停止服务
docker-compose stop

# 重启服务
docker-compose restart

# 查看日志
docker-compose logs -f

# 删除服务（保留数据）
docker-compose down

# 删除服务（包含数据卷）
docker-compose down -v
```

Trong bảng chùa:

2. Chọn "giả tĩnh"
3. Thêm các quy tắc sau:

### 9. Cấu hình trang Nginx

```bash
# 创建站点配置
vim /etc/nginx/conf.d/crmeb.conf
```

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /var/www/crmeb/public;
    index index.php index.html;

    # 日志配置
    access_log /var/log/nginx/crmeb_access.log;
    error_log /var/log/nginx/crmeb_error.log;

    # 静态文件缓存
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|woff|woff2|ttf|svg)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # 主路由规则
    location / {
        try_files $uri $uri/ /index.php?s=$uri&$args;
    }

    # PHP处理
    location ~ \.php$ {
        fastcgi_pass 127.0.0.1:9000;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;

        # 超时配置
        fastcgi_connect_timeout 300;
        fastcgi_send_timeout 300;
        fastcgi_read_timeout 300;
    }

    # 禁止访问敏感文件
    location ~ /\.(env|git|htaccess) {
        deny all;
    }
}
```

```bash

```

## 🔧 Cấu hình sau khi cài đặt

### 1. Định cấu hình HTTPS (được khuyến nghị)

```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate /etc/nginx/ssl/crmeb.crt;
    ssl_certificate_key /etc/nginx/ssl/crmeb.key;
    ssl_session_timeout 5m;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-RSA-AES128-GCM-SHA256:HIGH:!aNULL:!MD5:!RC4:!DHE;

    # 其他配置同上...
}

# HTTP重定向到HTTPS
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}
```

### 2. Cấu hình bộ lưu trữ đám mây Qiniu (tùy chọn)
