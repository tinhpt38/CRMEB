# Tự động tạo gói database tiếng Việt (CRMEB)

Tài liệu này hướng dẫn tạo file SQL tiếng Việt để import trực tiếp vào hệ thống CRMEB.

## 1) Điều kiện trước khi chạy

- Có thể chạy command ThinkPHP trong thư mục backend `crmeb/`.
- Chọn **một trong hai** cách dịch:

### A) Dịch qua Volcengine (cần key)

- Cấu hình trong hệ thống: `hs_accesskey`, `hs_secretkey`.
- Chạy với `--engine=volc` hoặc `--engine=auto` khi đã có key.

### B) Dịch cục bộ — không cần `hs_accesskey` / `hs_secretkey` (khuyến nghị khi không có key)

- Cài **Python 3** trên máy chạy lệnh.
- Cài dependency **mặc định** (nhẹ, tránh lỗi `spacy`/`thinc` trên Python 3.9):

```bash
cd crmeb
pip3 install -r crmeb/bin/requirements-local-translate.txt
```

  Chỉ cần **`deep-translator`**: dịch zh→vi qua Google web (không API key; có thể bị giới hạn tần suất).

- **Không nên** trên Python 3.9: `pip install argostranslate` bản mới (1.11+) vì kéo **spacy** và lỗi build `thinc`. Muốn Argos offline: dùng **Python 3.10+** và xem `crmeb/crmeb/bin/requirements-argos-optional.txt`.

Biến môi trường tùy chọn:

- `CRMEB_PYTHON`: đường dẫn tới binary Python (mặc định tìm `python3` / `python`).
- `CRMEB_LOCAL_TRANSLATE_SCRIPT`: đường dẫn tới file script riêng nếu bạn tự đặt.

## 2) Command

Đã bổ sung command qua `util`:

```bash
cd crmeb
php think util langdbvi
```

- Mặc định `--engine=auto`: **nếu có key Volcengine thì dùng Volc; nếu không có key thì dùng dịch cục bộ (Python + Argos)**.

### Cách dịch cục bộ (ép buộc không dùng key)

```bash
php think util langdbvi --engine=local
```

### Cách dùng Volcengine (bắt buộc có key)

```bash
php think util langdbvi --engine=volc
```

Command sẽ làm các bước:

1. Quét text tiếng Trung từ các bảng preset nghiệp vụ.
2. Đồng bộ text vào `eb_lang_code` theo cơ chế i18n sẵn có.
3. Dịch sang `vi-VN` và xuất file SQL để import.

## 3) Tùy chọn nâng cao

```bash
php think util langdbvi --tables=store_product,store_category,article --source=1 --chunk=300 --translate_batch=80 --engine=local
```

- `--tables`: danh sách bảng cần quét.
- `--source`: `type_id` nguồn (mặc định `1` = 中文).
- `--chunk`: số bản ghi scan mỗi batch.
- `--translate_batch`: số câu gửi API dịch mỗi batch (Volcengine / local batch).
- `--engine`: `auto` | `volc` | `local`.

## 4) File SQL đầu ra

File được tạo trong thư mục `runtime/`:

- `runtime/lang_vi_package_YYYYmmdd_HHMMSS.sql`

File này chứa:

- Bảo đảm có `lang_type` cho `vi-VN`.
- Gán mapping `lang_country` cho `vi-VN`.
- Toàn bộ dữ liệu `lang_code` tiếng Việt (`type_id` của `vi-VN`).

## 5) Import file SQL

```bash
mysql -u<user> -p<pass> <database_name> < runtime/lang_vi_package_YYYYmmdd_HHMMSS.sql
```

Sau khi import, hệ thống có thể dùng header `cb-lang: vi-VN` để trả ngôn ngữ tiếng Việt theo cơ chế sẵn có.
