# 系统分销开发文档

##1. Tổng quan về cơ chế phân phối

Hệ thống CRMEB triển khai các chức năng phân phối hoàn chỉnh và hỗ trợ các chức năng cốt lõi như phân phối thứ cấp, mức độ phân phối, tính toán hoa hồng và xem xét ứng dụng phân phối.Hệ thống phân phối thực hiện khuyến mãi và phân phối hoa hồng giữa người dùng thông qua chuỗi quan hệ khuyến mãi, giúp thương nhân mở rộng kênh bán hàng và nâng cao mức độ gắn bó của người dùng.

### 1.1 Chức năng cốt lõi

- **Phân phối phụ**: Hỗ trợ các mối quan hệ phân phối chính và phụ, mức phân phối có thể định cấu hình
- **Cấp độ phân phối**: Hỗ trợ các cấp độ phân phối đa cấp và các cấp độ khác nhau được hưởng tỷ lệ hoa hồng khác nhau
- **Tính toán hoa hồng**: Hỗ trợ tính toán hoa hồng dựa trên giá bán sản phẩm và có thể định cấu hình tỷ lệ hoa hồng cấp một và cấp hai
- **Giảm giá tự mua**: Hỗ trợ chức năng giảm giá tự mua của người dùng và có thể được cấu hình để kích hoạt hoặc không.
- **分销申请**：支持用户申请成为分销员，需管理员审核
- **Quản lý quan hệ phân phối**: Hỗ trợ xem và quản lý chuỗi quan hệ phân phối của người dùng
- **Rút hoa hồng**: Hỗ trợ nhà phân phối đăng ký rút hoa hồng, sẽ được cấp sau khi quản trị viên xem xét.

## 2. Thành phần cốt lõi

### 2.1 Mô hình dữ liệu

- **AgentLevel**: Mô hình cấp độ phân phối, xác định thông tin cấp độ phân phối và tỷ lệ hoa hồng
- **AgentLevelTask**：分销等级任务模型，定义升级所需完成的任务
- **AgentLevelTaskRecord**: Mô hình ghi nhiệm vụ cấp độ phân phối, ghi lại trạng thái hoàn thành nhiệm vụ của người dùng
- **Người dùng**: Mô hình người dùng, các trường liên quan đến phân phối mở rộng ( Spread_uid, Agent_level, v.v.)
- **StoreOrder**: mẫu đơn hàng, ghi nhận thông tin hoa hồng của đơn hàng
- **UserExtract**: Mô hình rút tiền của người dùng, ghi lại ứng dụng rút tiền của người dùng
- **UserBrokerage**: Mô hình hoa hồng người dùng, ghi lại luồng hoa hồng của người dùng

### 2.2 Lớp dịch vụ

- **AgentLevelServices**: Các dịch vụ ở cấp độ phân phối, xử lý logic bổ sung, xóa, sửa đổi và nâng cấp của các cấp độ phân phối
- **AgentManagerServices**: Dịch vụ quản lý phân phối, xử lý việc quản lý và thống kê nhà phân phối
- **Dịch vụ người dùng**: Dịch vụ người dùng, các chức năng liên quan đến phân phối mở rộng
- **StoreOrderCreateServices**: Dịch vụ tạo đơn hàng, tính hoa hồng xử lý đơn hàng

### 2.3 Bộ điều khiển

- **AgentManager**: Bộ điều khiển quản lý nhà phân phối, cung cấp danh sách nhà phân phối và chức năng thống kê
- **AgentLevel**: Bộ điều khiển mức phân phối, cung cấp chức năng quản lý mức phân phối
- **SpreadApply**: Bộ điều khiển ứng dụng phân phối, xử lý ứng dụng phân phối của người dùng

## 3. Cấu hình phân phối

### 3.1 Các mục cấu hình hệ thống

Các hạng mục cấu hình cốt lõi của chức năng phân phối được quản lý trong cấu hình hệ thống và chủ yếu bao gồm:

| Mục cấu hình | Mô tả | Giá trị mặc định |
|-------|------|-------|
| môi giới_func_status | Công tắc chức năng phân phối | 0 |
| store_brokerage_ratio | Tỷ lệ hoa hồng phân phối cấp độ đầu tiên | 0 |
| store_brokerage_two | Tỷ lệ hoa hồng phân phối thứ cấp | 0 |
| môi giới_level | Cấp độ phân phối (1 hoặc 2) | 2 |
| store_brokerage_statu | Chuyển đổi ứng dụng nhà phân phối | 0 |
| store_brokerage_bind_status | Chế độ ràng buộc môi giới | 0 |
| is_self_brokerage | Có bật tính năng giảm giá khi tự mua hàng hay không | 0 |

### 3.2 Ví dụ về cấu hình

```php
// 获取分销功能开关状态
sys_config('brokerage_func_status');

// 获取一级分销佣金比例
sys_config('store_brokerage_ratio');

// 获取二级分销佣金比例
sys_config('store_brokerage_two');
```

## 4. Mức độ phân phối

### 4.1 Mô hình phân cấp

Mô hình cấp độ phân phối xác định thông tin cấp độ của nhà phân phối, bao gồm tỷ lệ hoa hồng, điều kiện nâng cấp, v.v.:

```php
class AgentLevel extends BaseModel
{
    protected $pk = 'id';
    protected $name = 'agent_level';
    
    // 关联等级任务
    public function task()
    {
        return $this->hasMany(AgentLevelTask::class, 'level_id', 'id')->where('is_del', 0);
    }
}
```

### Cơ chế nâng cấp cấp 4.2

Người dùng có thể nâng cấp cấp độ phân phối của mình bằng cách hoàn thành các nhiệm vụ được chỉ định và tận hưởng tỷ lệ hoa hồng cao hơn:

```php
// 检查用户等级任务完成情况
public function checkUserLevelFinish($uid)
{
    // 获取用户当前等级
    $userInfo = app()->make(UserServices::class)->getUserInfo($uid);
    if (!$userInfo) return false;
    
    // 获取下一级等级信息
    $levelList = $this->dao->getList(['is_del' => 0, 'status' => 1], '*', [], 0, 0, $userInfo['agent_level']);
    
    // 检查任务完成情况
    foreach ($levelList as $levelInfo) {
        // 获取等级任务
        $task_list = $levelInfo['task'] ?? [];
        
        // 检查每个任务是否完成
        foreach ($task_list as $task) {
            $levelTaskServices->checkLevelTaskFinish($uid, (int)$task['id'], $task);
        }
        
        // 统计完成的任务数量
        $finish_task = $levelTaskRecordServices->count([
            'level_id' => $levelInfo['id'], 
            'uid' => $uid, 
            'task_id' => array_column($task_list, 'id')
        ]);
        
        // 任务完成升级
        if ($finish_task >= $levelInfo['task_num']) {
            $userServices->update($uid, ['agent_level' => $levelInfo['id']]);
        }
    }
}
```

## 5. Tính hoa hồng

### 5.1 Logic tính toán hoa hồng

Việc tính toán hoa hồng hoàn tất khi đơn hàng được tạo và được tính dựa trên giá bán sản phẩm và tỷ lệ hoa hồng:

```php
public function computeOrderProductTruePrice($cartInfo, $priceData, $addressId, $uid, $orderInfo)
{
    // 获取分销佣金比例和返佣人员
    [$storeBrokerageRatio, $storeBrokerageTwo, $spread_one_uid, $spread_two_uid] = $this->getSpreadDate($uid);
    
    // 计算佣金
    if ($storeBrokerageRatio > 0 || $storeBrokerageTwo > 0 || $staffPercent > 0 || $agentPercent > 0 || $divisionPercent > 0) {
        // 计算商品售价
        $price = bcsub((string)$cart['truePrice'], (string)$cart['truePostage'], 2);
        
        // 计算一级佣金
        if ($storeBrokerageRatio > 0) {
            $brokerageRatio = bcdiv($storeBrokerageRatio, 100, 4);
            $oneBrokerage = bcmul((string)$price, (string)$brokerageRatio, 2);
        }
        
        // 计算二级佣金
        if ($storeBrokerageTwo > 0) {
            $brokerageTwo = bcdiv($storeBrokerageTwo, 100, 4);
            $twoBrokerage = bcmul((string)$price, (string)$brokerageTwo, 2);
        }
        
        // 记录佣金信息
        $cart['one_brokerage'] = $oneBrokerage;
        $cart['two_brokerage'] = $twoBrokerage;
    }
    
    return [$cartInfo, [$spread_one_uid, $spread_two_uid]];
}
```

### 5.2 Kiểm soát mức độ phân phối

Hệ thống hỗ trợ cấu hình mức phân phối (cấp 1 hoặc 2) và cách tính hoa hồng có thể được điều chỉnh theo cấu hình:

```php
// 判断返佣层级为一级时，将二级用户uid和二级分佣比例改为0
if (sys_config('brokerage_level') == 1) {
    $storeBrokerageTwo = $spread_two_uid = 0;
}
```

### 5.3 Tự mua giảm giá

Hệ thống hỗ trợ cấu hình chức năng tự mua hàng giảm giá của người dùng:

```php
// 获取上级和上上级的uid，开启自购获取自己和上级的uid
$spread_one_uid = $userServices->getSpreadUid($uid, $userInfo);
```

## 6. Ứng dụng phân phối và đánh giá

### Ứng dụng phân phối 6.1

Người dùng có thể đăng ký để trở thành nhà phân phối và thông tin ứng dụng được lưu trữ trong cơ sở dữ liệu và chờ quản trị viên xem xét:

```php
// 分销申请接口
public function apply()
{
    // 检查分销功能是否开启
    if (!sys_config('brokerage_func_status')) {
        throw new ApiException(100209);
    }
    
    // 检查是否已经是分销员
    if ($this->services->checkUserPromoter($this->uid)) {
        throw new ApiException(100210);
    }
    
    // 提交申请
    $this->services->applySpread($this->uid, $this->request->post());
    
    return app('json')->success(100211);
}
```

### 6.2 Xét duyệt ứng dụng

Quản trị viên có thể xem xét ứng dụng phân phối của người dùng. Sau khi vượt qua đánh giá, người dùng sẽ trở thành nhà phân phối:

```php
// 分销申请审核接口
public function applyExamine($id, $uid, $status)
{
    // 检查参数
    if (!$id || !$uid || !in_array($status, [0, 1])) {
        throw new AdminException(100026);
    }
    
    // 审核申请
    $this->services->examineSpreadApply($id, $uid, $status);
    
    return app('json')->success(100014);
}
```

##7. Quản lý quan hệ phân phối

### 7.1 Ràng buộc mối quan hệ khuyến mãi

Khi người dùng đăng ký thông qua link chia sẻ hoặc mã QR, mối quan hệ khuyến mãi sẽ tự động được ràng buộc:

```php
// 保存用户信息并绑定推广关系
public function setUserInfo($user, int $spreadUid = 0, string $userType = 'wechat')
{
    $data = [
        // 用户基本信息
        'nickname' => $user['nickname'] ?? '',
        'avatar' => $user['headimgurl'] ?? '',
        // ... 其他字段
    ];
    
    // 绑定推广关系
    if ($spreadUid) {
        $data['spread_uid'] = $spreadUid;
        $data['spread_time'] = time();
    }
    
    // 保存用户信息
    $res = $this->dao->save($data);
    
    // 触发用户注册事件
    event('UserRegisterListener', [$spreadUid, $userType, $user['nickname'], $res->uid, 1]);
    
    return $res;
}
```

### 7.2 Truy vấn mối quan hệ thăng tiến

Hệ thống cung cấp giao diện truy vấn chuỗi quan hệ khuyến mãi của người dùng:

```php
// 获取用户的一级和二级推广用户
public function getSpreadList(int $uid, array $where, bool $is_page = true)
{
    // 获取一级推广用户
    $one_list = $this->dao->getSpreadUserList($where, $uid, 1, $is_page);
    
    // 获取二级推广用户
    $two_list = $this->dao->getSpreadUserList($where, $uid, 2, $is_page);
    
    return ['one_list' => $one_list, 'two_list' => $two_list];
}
```

## 8. Nhiệm vụ cấp độ phân phối

### 8.1 Loại nhiệm vụ

Hệ thống hỗ trợ nhiều loại nhiệm vụ cấp phân phối:

- **Số người cần quảng cáo**: Quảng bá một số lượng người dùng nhất định
- **Số tiền đặt hàng**: Hoàn thành đơn hàng với số tiền được chỉ định
- **Số lượng đơn hàng**: Hoàn thành số lượng đơn hàng quy định
- **Số tiền tự mua**: Hàng tự mua với số lượng xác định
- **Số lượng tự mua**: Tự mua số lượng hàng hóa quy định

### 8.2 Kiểm tra hoàn thành nhiệm vụ

Hệ thống sẽ thường xuyên kiểm tra trạng thái hoàn thành nhiệm vụ của người dùng và tự động nâng cấp khi đáp ứng đủ điều kiện:

```php
// 检查任务完成情况
public function checkLevelTaskFinish($uid, $taskId, $task)
{
    // 根据任务类型检查完成情况
    switch ($task['type']) {
        case 1: // 推广人数
            $count = $this->dao->getSpreadUserCount($uid);
            break;
        case 2: // 订单金额
            $count = $this->dao->getUserOrderAmount($uid);
            break;
        case 3: // 订单数量
            $count = $this->dao->getUserOrderCount($uid);
            break;
        // ... 其他任务类型
    }
    
    // 更新任务完成记录
    if ($count >= $task['value']) {
        $this->taskRecordServices->updateTaskRecord($uid, $taskId);
    }
}
```

## 10. Các phương pháp hay nhất

### 10.1 Thiết kế cấp độ phân phối

- **Đặt số lượng cấp hợp lý**: Nên đặt 3-5 cấp phân bổ. Quá nhiều cấp độ sẽ làm tăng độ phức tạp trong quản lý.
- **Tỷ lệ hoa hồng cài đặt theo độ dốc**: Tỷ lệ hoa hồng ở các cấp khác nhau phải khác nhau đáng kể để khuyến khích người dùng nâng cấp
- **设置合理的升级条件**：升级条件应该具有可实现性，避免设置过高的门槛

### 10.2 Cài đặt hoa hồng

- **Tỷ lệ hoa hồng được đặt hợp lý**: Đặt tỷ lệ hoa hồng hợp lý dựa trên tỷ lệ lợi nhuận của sản phẩm để tránh ảnh hưởng đến lợi nhuận của người bán.
- **Kiểm soát mức độ phân phối**: Nên sử dụng phân phối thứ cấp để tuân thủ các quy định quốc gia có liên quan.
- **Cho phép giảm giá khi tự mua**: Nó có thể làm tăng sự nhiệt tình mua hàng của người dùng và tăng doanh số bán hàng.

### 10.3 Quản lý quan hệ khuyến mãi

- **Quy tắc khuyến mãi rõ ràng**: Xây dựng quy tắc khuyến mãi rõ ràng để tránh tranh chấp giữa người dùng
- **Thường xuyên dọn dẹp các mối quan hệ không hợp lệ**: Thường xuyên dọn dẹp các mối quan hệ khuyến mãi không hoạt động lâu dài để dữ liệu luôn sạch sẽ
- **Bảo vệ quyền riêng tư của người dùng**: Khi hiển thị các mối quan hệ quảng cáo, hãy chú ý bảo vệ thông tin riêng tư của người dùng

## 11. Câu hỏi thường gặp

### 11.1 Chức năng phân phối không có hiệu lực

- Kiểm tra xem công tắc chức năng phân phối đã được bật chưa
- 检查佣金比例是否设置正确
- Kiểm tra xem người dùng có đủ điều kiện để được khuyến mãi hay không

### 11.2 Lỗi tính toán hoa hồng

- Kiểm tra xem tỷ lệ hoa hồng có được đặt chính xác không
- Kiểm tra số tiền đặt hàng có đúng không
- Kiểm tra xem cài đặt mức phân phối có chính xác không

### 11.3 Liên kết mối quan hệ quảng cáo không thành công

- Kiểm tra link khuyến mãi có chính xác không
- Kiểm tra xem các thông số khuyến mãi có được truyền đúng hay không
- Kiểm tra xem quá trình đăng ký người dùng có đúng không

### 11.4 Cấp độ phân phối sẽ không được nâng cấp

- Kiểm tra xem các điều kiện nâng cấp có được đặt chính xác không
- Kiểm tra xem việc hoàn thành nhiệm vụ có đúng không
- Kiểm tra xem có lỗi trong logic nâng cấp không

##12. Tóm tắt

Chức năng phân phối của hệ thống CRMEB cung cấp giải pháp phân phối thứ cấp hoàn chỉnh, hỗ trợ các chức năng cốt lõi như mức phân phối, tính toán hoa hồng và xem xét ứng dụng phân phối.Bằng cách định cấu hình và sử dụng đúng chức năng phân phối, người bán có thể mở rộng kênh bán hàng, cải thiện mức độ gắn bó của người dùng và đạt được mức tăng trưởng doanh số.Các nhà phát triển có thể mở rộng nhiều chức năng phân phối hơn dựa trên khung hiện có dựa trên nhu cầu kinh doanh, chẳng hạn như phân phối ba cấp độ, phần thưởng nhóm, v.v.
