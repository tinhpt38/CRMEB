# Mô tả quy trình kinh doanh

##📋 Quy trình kinh doanh cốt lõi

### 🛒 Quy trình tạo đơn hàng
1. Người dùng chọn sản phẩm → thêm vào giỏ hàng → tạo đơn hàng
2. Xác minh đơn hàng (hàng tồn kho, giá cả, phiếu giảm giá)
3. Tạo dữ liệu đơn hàng
4. khấu trừ hàng tồn kho
5. Gửi thông báo đặt hàng

### 💳 Quy trình xử lý thanh toán
1. Người dùng chọn phương thức thanh toán
2. Giao diện thanh toán cuộc gọi
3. Gọi lại kết quả thanh toán
4. Cập nhật trạng thái đơn hàng
5. Ghi lại lịch sử thanh toán

### 📦 Quy trình vận chuyển
1. Kiểm tra trạng thái đơn hàng (đã thanh toán)
2. Tạo hóa đơn
3. Giao diện hậu cần cuộc gọi
4. Cập nhật trạng thái vận chuyển
5. Thông báo cho người dùng thông tin hậu cần

### 🔄Quy trình hậu mãi
1. Người dùng gửi đơn đăng ký sau bán hàng
2. Xem xét các yêu cầu sau bán hàng
3. Quy trình hoàn tiền/đổi hàng
4. Cập nhật hàng tồn kho và tài chính
5. Hoàn tất quy trình hậu mãi

## ⏱️ Quy trình tác vụ không đồng bộ
- Hàng đợi tin nhắn xử lý các tác vụ liên quan đến đơn hàng
- Thống kê dữ liệu xử lý tác vụ theo lịch trình
- Hoạt động xử lý hàng loạt tác vụ nền
