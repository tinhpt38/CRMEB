# Mô tả tài liệu tác vụ xếp hàng hệ thống CRMEB

## Tổng quan

CRMEB 系统采用基于 Redis 的消息队列机制，通过 ThinkPHP 框架的队列组件实现异步任务处理。队列系统在提高系统性能、优化用户体验、保证数据一致性方面发挥着重要作用。

## Kiến trúc hệ thống hàng đợi

### 1. Ngăn xếp công nghệ
- **Trình điều khiển hàng đợi**: Redis (chính) + Cơ sở dữ liệu (dự phòng) + Đồng bộ hóa (đồng bộ hóa)
- **Dịch vụ xếp hàng**: Hàng đợi ThinkPHP
- **Lịch trình**: Workerman + Crontab
- **Lập lịch tác vụ**: xử lý không đồng bộ dựa trên sự kiện

### 2. Thành phần cốt lõi

#### Cấu hình hàng đợi 2.1 (config/queue.php)
```php
return [
    'default'     => 'redis',           // 默认驱动
    'prefix'      => 'crmeb_',          // 队列前缀
    'connections' => [
        'redis' => [
            'driver'     => 'redis',
            'queue'      => 'CRMEB',     // 队列名称
            'host'       => '127.0.0.1',
            'port'       => 6379,
            'password'   => '',
            'select'     => 0,
        ],
    ],
    'failed' => [
        'type'  => 'database',
        'table' => 'failed_jobs',       // 失败任务表
    ],
];
```

#### 2.2 Lớp nhiệm vụ cơ bản (BaseJobs)
```php
abstract class BaseJobs implements JobInterface
{
    // 任务执行入口
    public function fire(Job $job, $data): void
    
    // 任务重试机制
    protected function runJob(string $action, Job $job, array $infoData, int $errorCount = 3)
}
```

#### 2.3 Đặc điểm hàng đợi (QueueTrait)
```php
trait QueueTrait
{
    // 立即推送任务
    public static function dispatch($action, array $data = [], string $queueName = null)
    
    // 延迟推送任务
    public static function dispatchSecs(int $secs, $action, array $data = [], string $queueName = null)
}
```

## Phân loại tác vụ hàng đợi

### 1. Các công việc liên quan đến đơn hàng

#### 1.1 OrderJob - Nhiệm vụ xử lý đơn hàng
**Chức năng**: Xử lý tiếp theo sau khi thanh toán đơn hàng thành công
**Thời gian kích hoạt**: Khi thanh toán đơn hàng thành công
**Xử lý chính**:
- Tính toán tiết kiệm sản phẩm
- Cập nhật số lượng đơn hàng thanh toán của người dùng
- Phát hiện và thiết lập danh tính người quảng bá
- Thêm thẻ mua hàng của người dùng
- Gửi tin nhắn thông báo dịch vụ khách hàng
- Kiểm tra nâng cấp cấp thành viên
- Gửi tin nhắn đặt hàng mới đến nền

```php
// 使用示例
OrderJob::dispatch('doJob', [$orderInfo]);
```

#### 1.2 OrderCreateAfterJob - Xử lý sau khi tạo đơn hàng
**Chức năng**: Xử lý dữ liệu sau khi tạo đơn hàng
**Thời gian kích hoạt**: Sau khi lệnh được tạo
**Xử lý chính**:
- Tính giá thực tế của đơn hàng
- Xử lý các mối quan hệ xúc tiến
- Tính toán phân phối hoa hồng
- Cập nhật thông tin bổ sung đơn hàng

#### 1.3 UnpackedOrderCancelJob - Hủy đơn hàng chưa thanh toán
**Chức năng**: Tự động hủy đơn hàng ngoài giờ chưa thanh toán
**Thời gian kích hoạt**: nhiệm vụ đã lên lịch hoặc hàng đợi trì hoãn
**Xử lý logic**:
- Kiểm tra trạng thái thanh toán đơn hàng
- Điểm hoàn tiền và phiếu giảm giá
- Khôi phục tồn kho sản phẩm
- Đánh dấu đơn hàng là đã hủy

```php
// 延迟30分钟后执行
UnpaidOrderCancelJob::dispatchSecs(1800, 'doJob', [$orderId]);
```

## Hệ thống nhiệm vụ theo lịch trình

### 1. Lệnh hẹn giờ
Lập lịch tác vụ thời gian được triển khai dựa trên Workerman

```bash
# 启动定时任务
php think timer start

# 守护进程方式启动
php think timer start -d

# 停止定时任务
php think timer stop

# 重启定时任务
php think timer reload
```

### 2. Nhiệm vụ theo lịch trình của hệ thống
Bảng cơ sở dữ liệu: `system_crontab`

**Mô tả trường**:
- `name`: tên nhiệm vụ
- `task_type`: loại nhiệm vụ
- `mark`: ID nhiệm vụ
- `content`: Nội dung nhiệm vụ
- `max_execution_time`: Thời gian thực hiện tối đa
- `execution_cycle`: chu kỳ thực hiện
- `is_open`: Có bật hay không
- `next_execution_time`: lần thực hiện tiếp theo
- `last_execution_time`: Lần thực hiện cuối cùng

### 3. Tích hợp sẵn các tác vụ theo lịch trình

#### 3.1 Liên quan đến đơn hàng
- **Hủy đơn hàng chưa thanh toán**: Được kiểm tra mỗi phút
- **Đã xóa các mặt hàng bán trước**: Được kiểm tra mỗi giờ
- **Xử lý lỗi nhóm**: Kiểm tra 5 phút một lần

#### 3.2 Thống kê
- **Tóm tắt thống kê hàng ngày**: Thực hiện vào mỗi buổi sáng
- **Phân tích hành vi người dùng**: Được thực hiện mỗi giờ
- **Thống kê bán hàng**: Thực hiện hàng ngày

#### 3.3 Bảo trì hệ thống
- **Làm sạch nhật ký**: Thực hiện hàng tuần
- **Dọn dẹp tập tin tạm thời**: Thực hiện hàng ngày
- **Làm mới bộ đệm**: thực hiện theo lịch trình

## Giám sát và quản lý hàng đợi

### 1. Giám sát trạng thái hàng đợi
```php
// 检查队列状态
Queue::instance()->getQueueInfo();

// 获取队列长度
Queue::instance()->getQueueLength();

// 获取失败任务
Queue::instance()->getFailedJobs();
```

### 2. Quản lý tác vụ
```php
// 重新执行失败任务
Queue::instance()->retryFailed($jobId);

// 清空队列
Queue::instance()->clearQueue($queueName);

// 暂停队列
Queue::instance()->pauseQueue($queueName);
```

### 3. Ghi nhật ký
Tất cả các nhiệm vụ hàng đợi đều có nhật ký chi tiết:
- Nhật ký thực hiện thành công
- Nhật ký thử lại thất bại
- Thông tin ngăn xếp ngoại lệ
- Thống kê thực hiện hiệu suất

## Các phương pháp hay nhất về cấu hình hàng đợi

### 1. Nhóm hàng đợi
Phân loại theo tầm quan trọng của doanh nghiệp:
```php
// 高优先级队列
'order_pay'     => 'CRMEB_ORDER_PAY'
'sms'           => 'CRMEB_SMS'
'email'         => 'CRMEB_EMAIL'

// 普通优先级队列
'statistics'    => 'CRMEB_STATISTICS'
'log'           => 'CRMEB_LOG'

// 低优先级队列
'report'        => 'CRMEB_REPORT'
'cleanup'       => 'CRMEB_CLEANUP'
```

### 2. Thử lại chiến lược
```php
// 不同任务的重试次数
'order_pay'     => 3      // 支付任务重试3次
'sms'           => 5      // 短信任务重试5次
'email'         => 3      // 邮件任务重试3次
'statistics'    => 1      // 统计任务重试1次
```

### 3. Cài đặt độ trễ
```php
// 常见延迟时间
UnpaidOrderCancelJob::dispatchSecs(1800, 'doJob', [$orderId]);  // 30分钟
OrderRemindJob::dispatchSecs(86400, 'doJob', [$orderId]);       // 24小时
CleanupJob::dispatchSecs(604800, 'doJob', [$data]);             // 7天
```

## Đề xuất tối ưu hóa hiệu suất

### 1. Tối ưu hóa hàng đợi
- Sử dụng cụm Redis để cải thiện tính khả dụng
- Đặt số lượng hàng đợi hợp lý để tránh điểm nóng
- Thường xuyên dọn dẹp dữ liệu hàng đợi đã hết hạn
- Theo dõi độ dài hàng đợi và mở rộng kịp thời

### 2. Tối ưu hóa tác vụ
- Tránh thực hiện các nhiệm vụ riêng lẻ quá phức tạp
- Phân chia hợp lý các nhiệm vụ lớn thành các nhiệm vụ nhỏ
- Sử dụng các giao dịch để đảm bảo tính nhất quán của dữ liệu
- Thêm kiểm soát thời gian chờ để tránh bị chặn

### 3. Tối ưu hóa tài nguyên
- Kiểm soát số lượng tác vụ đồng thời
- Đặt giới hạn bộ nhớ phù hợp
- Tối ưu hóa hiệu suất truy vấn cơ sở dữ liệu
- Sử dụng kết nối tổng hợp để giảm chi phí

## Khắc phục sự cố

### 1. Câu hỏi thường gặp

#### 1.1 Tích lũy hàng đợi
**Hiện tượng**: Độ dài hàng đợi tiếp tục tăng
**Nguyên nhân**: Tốc độ tiêu thụ thấp hơn tốc độ sản xuất
**gỡ rối**:
- Tăng số lượng quy trình tiêu dùng
- Tối ưu hóa hiệu quả thực hiện nhiệm vụ
- Kiểm tra việc sử dụng tài nguyên hệ thống

#### 1.2 Thực hiện lặp lại nhiệm vụ
**Hiện tượng**: Một tác vụ được thực thi nhiều lần
**Nguyên nhân**: Hàng đợi nhiệm vụ trùng lặp hoặc vấn đề bình thường
**gỡ rối**:
- Thêm mã định danh duy nhất của nhiệm vụ
- Thực hiện kiểm tra idempotence
- Tối ưu hóa logic thử lại nhiệm vụ

#### 1.3 Rò rỉ bộ nhớ
**Hiện tượng**: Bộ nhớ quy trình tiếp tục phát triển
**Lý do**: Có tài nguyên trong task chưa được giải phóng.
**gỡ rối**:
- Kiểm tra tài liệu tham khảo đối tượng
- Thả vật lớn kịp thời
-Khởi động lại quy trình tiêu dùng theo định kỳ

### 2. Xử lý cấp cứu

#### 2.1 Tạm dừng hàng đợi
```bash
# 暂停所有队列
php think queue:pause

# 暂停指定队列
php think queue:pause --queue=order_pay
```

#### 2.2 Buộc xóa
```bash
# 清空指定队列
php think queue:clear --queue=statistics

# 清空所有队列
php think queue:clear --all
```

#### 2.3 Xây dựng lại hàng đợi
```bash
# 重建队列表
php think queue:table

# 重新发布失败任务
php think queue:retry all
```

## Hướng dẫn phát triển

### 1. Tạo tác vụ mới

#### 1.1 Tạo lớp nhiệm vụ
```php
<?php
namespace app\jobs;

use crmeb\basic\BaseJobs;
use crmeb\traits\QueueTrait;

class CustomJob extends BaseJobs
{
    use QueueTrait;
    
    /**
     * 执行任务
     * @param array $data
     * @return bool
     */
    public function doJob(array $data): bool
    {
        try {
            // 业务逻辑处理
            $this->processData($data);
            return true;
        } catch (\Exception $e) {
            // 记录错误日志
            Log::error('任务执行失败: ' . $e->getMessage());
            return false;
        }
    }
    
    private function processData(array $data): void
    {
        // 具体业务逻辑
    }
}
```
