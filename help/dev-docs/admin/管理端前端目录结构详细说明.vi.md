# Mô tả chi tiết cấu trúc thư mục front-end quản lý CRMEB

## 📋 Tổng quan dự án

**Ngăn xếp công nghệ**: Vue.js 2.x + Element UI + Vuex + SCSS
**Khung giao diện người dùng**: Giao diện người dùng phần tử + Bảng VXE + Trình quét Vue Awesome
**Phiên bản dự án**: CRMEB Standard Edition 5.6.2
**Chế độ phát triển**: Thành phần + Mô-đun + Bố cục đáp ứng
